从零开始优化windows的使用体验

发表于 2026-08-06 更新于 2026-09-04 本文字数： 1.3k 阅读时长 ≈ 5 分钟

前言

用习惯linux换到windows还是挺不习惯的，但是因为需要使用pr和ps那些专业软件，所以我只能换到windows了，不过刚装好windows还是挺不习惯的，系统太臃肿，还有一个和360一样恶心的安全中心，把我u盘的10几个破解软件全部删除了，所以本篇博文我从零开始优化windows使用体验，本篇博文除了推荐一些软件还会说明一些优化设置(在后半部分)

激活

如果你安装的系统不是家庭版，而且你也没有激活密钥，那么系统就会显示你未激活，就只能设置一些基本的东西，使用我们就需要先把系统激活一下，激活的话可以使用github的一个项目:
https://github.com/zbezj/HEU_KMS_Activator

声明:本文仅作技术研究与个人体验分享,不构成使用建议。相关操作可能违反软件许可协议或平台规则,请读者自行判断风险并承担后果,建议有条件的话优先购买正版/支持官方渠道。

清除烦人的安全中心

这个安全中心真的不能留下，留下保不齐哪天重要文件被删除了，这个安全中心如果只是手动关闭，那么过一会又会出现自己打开，所以常规的手段肯定是不行的，所以直接使用github的一个项目:
https://github.com/ionuttbara/windows-defender-remover

这个工具可以让你的安全中心消失，你只需要在项目发布页面下载软件，使用管理员权限运行，选择你需要的模式执行，完成后重新启动就没有安全中心了

在下载软件的时候尽量官网下载，不要在犄角旮旯里下载软件，这种行为是很容易中病毒的，中病毒的其中一个表现通常是cpu占用很高，任务管理器有一个进程特别高但是你没有安装这个软件，还有一个案例是伪装成谷歌浏览器开了30多个网页占用特别高，这些基本就是中病毒了，这种你只能重装系统了

屏蔽 360 系、百度系、腾讯系等等垃圾软件

为了防止电脑有360这些流氓软件所以使用这个项目来防止:
https://github.com/the1812/Malware-Patch

通过 Windows 策略和规则限制部分流氓软件、推广软件的安装和运行，防止这些软件威胁设备和数据安全

奉劝大家一定不要安装360安全卫士和其他的杀毒软件，不然你的电脑一定会比没有安装杀毒软件的时候还卡!因为它会后台静默安装一些流氓软件，占用大量系统资源，还会劫持浏览器的首页为360搜索，卸载的时候还可能无法完全卸载，那个时候你的电脑系统已经被”污染”了，这些都是本人亲身体验到的，所以请不要安装360和其他杀毒软件!

彻底卸载软件

使用默认方式卸载软件，可能后留下残留，尤其是国内软件，所以使用一款强力的软件就十分重要了，而geek十分适合，他会在卸载完成后扫描有没有残留，下面是他的软件官网
https://geekuninstaller.com/

c盘清理

c盘清理可以使用WindowsCleaner，软件除了c盘清理，还有软件迁移
https://github.com/darkmatter2048/WindowsCleaner

禁止系统更新

禁止系统更新可以使用windows update blocker，访问链接把仓库的所有文件下载下来就可以了
https://github.com/Hudrig0/Windows-Update-Blocker

禁用不必要的开机启动程序

打开设置的应用，在里面选择启动，把不需要开机自启动的软件关掉可以提升开机速度，比如关闭浏览器自启动

修改电源计划

打开设置的系统，在里面选择电源和睡眠，在里面选择其他电源设置，可以把平衡改成高性能提升性能，这里也可以更改屏幕关闭时间和睡眠时间

如果你的硬件配置完美符合软件硬件配置还是很卡，记得看看你是不是把HDMI线插主板上面而不是显卡上面了，之前我爸的主机就是插了好久的主板的😅，然后记得检查驱动十分安装好了，不过记住驱动可以运行就尽量不要更新驱动了，不然可能会发生不好的事情，然后安装驱动不要使用驱动总裁什么的，不然你的电脑会被”污染”的，老老实实在官网选择对应的驱动吧

结尾

最后我还是想说的是如果不是非必要尽量不用安装以盈利性质为目的闭源国内软件，你不能确认他会不会污染你的电脑，软件尽量选择开源软件

重装系统

有一说一技嘉的bios界面还是蛮不错的，安装好系统后打开，清清爽爽，没有污染物，不过除了系统重装以外，还需要安装驱动，不如就无法发挥性能了，尤其是显卡和主板的，安装驱动到官网下载对应驱动，系统版本要选择当前电脑版本，一定不要用驱动总裁这种，不然你的系统绝对会被污染，污染了就很难清理了

安装专业软件

专业软件肯定不可能是正常版，像ps,pr那些都是要钱的，所以只能用破解版，破解版可以在克隆窝和海盗湾下载安装了，也没什么好说的

使用NexAlloy模块白嫖谷歌相册原始画质无限存储

发表于 2026-07-28 更新于 2026-09-03 本文字数： 684 阅读时长 ≈ 2 分钟

前言

2021年6月1日google开始正式停止提供免费无限存储空间,从此每个谷歌账号就只有15GB 免费存储空间(谷歌相册，谷歌邮件和谷歌云端硬盘)，对于一些白嫖谷歌相册免费存储的就很难受，不过还是有一种解决方法的，就是买一个google Pixel XL，因为google Pixel XL可以享有谷歌相册无限存储，而且还是原始画质的，但是现在打开购物平台基本都是需要200到300的价格，为了白嫖谷歌相册原始画质无限存储花200多买一个手机也太亏了，不过如果你的手上有一台有root(超级用户)的手机，那么事情就好办了，因为只需要让谷歌认为我们的手机是google Pixel XL就可以了，而我们可以使用模块来让自己的设备伪装成google Pixel XL就可以了,不过最好不要使用主号，虽然封号风险很小但是也不是没有

声明:本文仅作技术研究与个人体验分享,不构成使用建议。相关操作可能违反软件许可协议或平台规则,请读者自行判断风险并承担后果

下载模块

我们使用NexAlloy模块来伪装机型，NexAlloy是一个 LSPosed 模块，它其实不只有白嫖谷歌相册存储这么一个功能，还有其他的功能

我们打开仓库的发布页面下载后缀名是.apk的文件，下面是发布页面
https://github.com/NexAlloy/NexAlloy/releases

LSPosed框架(注:原版的lsp已经停止更新，最高安卓支持版本为安卓14,如果高于安卓14则需要下载第三方版本)
原版
https://github.com/LSPosed/LSPosed
JingMatrix版(现改名叫Vector不叫LSPosed)
https://github.com/JingMatrix/Vector

shamkio(防检测)
https://github.com/LSPosed/LSPosed.github.io/releases

使用和配置

打开面具，在主页点击设置开启zygisk,在模块页面安装LSPosed和shamkio然后重启，重启完成后打开lsp，在模块页面点击NexAlloy然后点击启用模块，把谷歌相册和其他支持的软件全部勾选，在让谷歌相册强制停止运行后重新打开就可以生效了

验证是否生效

打开相机顺便拍几个照片，打开谷歌相册点击备份，备份完成点击关于看看刚才备份完成的新照片有没有显示此内容不会占用您的账号存储空间即可说明伪装成功，或者也可以看看15gb的存储有没有增加，如果没有，这事就成了

使用hexo和codeberg pages从零开始搭建个人博客

发表于 2026-07-25 更新于 2026-07-27 本文字数： 2k 阅读时长 ≈ 7 分钟

前言

拥有一个自己的博客网站听起来是一个很酷的事，你可以在博客里分享一些东西，它也许可以帮助到一些人，也可以让自己在互联网留下足迹，也许你会认为要买服务器买域名的，肯定要花不少钱，不过也有免费方案，例如我这个博客就是使用hexo框架，用codeberg的pages来托管自己的博客的，不过除了codeberg的pages服务，github也有pages服务，也就是我的副站，不过本篇博文只讲hexo和codeberg-pages从零开始搭建个人博客，github的找个时间再发布

注册账号

那么既然要使用codeberg pages服务那么肯定需要一个codeberg账号，如果没有就访问官方网站，Codeberg是一个代码托管平台，详细说明查看维基百科注册 codeberg账号这种小孩都会的东西我就不细说了，只需要准备一个可以正常使用的邮箱(最好是gmail)，然后注意一下自己的用户名,因为博客网址包含用户名称

安装软件

使用hexo我们需要nodejs和npm，我们使用包管理器安装
sudo pacman -S git nodejs npm

然后使用npm来全局安装hexo
sudo npm install -g hexo-cli

其他细节参考官方文档：
https://hexo.io/zh-cn/docs/

初始化博客

使用npm安装好hexo后，执行以下命令来初始化
hexo init blog

完成后就会在当前目录创建一个blog的文件夹，里面就是我们的博客本体,我们cd到该目录
cd blog

进入该目录后使用npm来补全依赖什么的
npm install

基本配置

打开_config.yml文件修改配置

其他细节参考官方文档：
https://hexo.io/zh-cn/docs/configuration

配置主题

hexo默认的主题，虽然算不上难看但是我不喜欢，因为它没有暗色然后样式我也不太喜欢所以我的博客使用了cactus主题，一个极简的响应式主题，我们使用git工具把主题克隆到我们博客themes
文件夹里面
git clone https://github.com/probberechts/hexo-theme-cactus.git themes/cactus

然后在_config.yml文件修改主题(不是主题的_config.yml，是博客根目录的_config.yml)

然后创建一些比如说关于,标签的页面
hexo new page about

文件在blog/source/about文件夹里，打开里面的index.md修改为

标签那些东西也是一样的操作

修改主题字体大小

正文字体大小设置

cactus主题默认的字体比较小，在阅读博文的时候就会比较费劲,打开blog/themes/cactus/source/css/_variables.styl

小标题字体大小设置

但是修改完成后你好发现虽然正文字体变大了但是小标题那些还是原来的大小，就会让正文比小标题还大，这样就让小标题失去它的作用了，我们需要修改`blog/themes/cactus/source/css/_extend.styl
h1,h2,h3这些是从大到小的标题大小

TOC字体大小设置

toc就是文章目录，但是还是老问题，toc字体太小了，所以打开blog/themes/cactus/source/css/_partial/post/actions_desktop.styl
修改#toc部分和上面的h1,h2,h3一样

其他设置

设置gruvbox主题配色

默认的cactus主题有三个主题，不过没有我最喜欢的gruvbox的主题，所以我们打开/home/uxtk/blog/themes/cactus/source/css/_colors/dark.styl 修改里面的配色

在blog/themes/cactus/_config.yml 确保colorscheme是dark

设置logo和图标图片

默认的图片是一个可爱的仙人掌，所以我们要修改logo图片,在blog/themes/cactus/source/images放入自己的logo的图片,然后在blog/themes/cactus/_config.yml 修改为自己的图片

设置导航栏

在blog/themes/cactus/_config.yml修改nav部分

设置社交链接

在blog/themes/cactus/_config.yml修改social_links部分

设置主页的文章显示数量

默认只显示最新的5篇文章，在blog/themes/cactus/_config.yml修改posts_overview部分

你也可以顺便在主页显示标签云
tags_overview: true

设置页面宽度

默认的宽度太窄了，我们修改page_width部分
page_width: 80

顺便更正真正的建站时间

本地查看一下效果

修改好这些后就可以在本地查看一下效果怎么样了，在博客根目录
下执行命令
hexo clean && hexo g && hexo s

然后在浏览器输入http://localhost:4000/就可以本地查看了

上传到仓库

安装hexo-deployer-git插件

hexo-deployer-git用来把生成好的网页文件自动推送到远程仓库,不用再手动git到仓库,在博客根目录使用npm安装插件
npm install hexo-deployer-git --save

打开根目录下的 _config.yml 文件在找到 deploy 配置项，修改为你的仓库信息

配置git

git在使用之前需要添加用户名和邮箱才可以使用,输入以下命令
git config --global user.name "你的用户名"

git config --global user.email "你的邮箱"

新建codeberg仓库

打开主页右上方的加号，选择创建仓库，仓库名称填入pages，然后创建仓库

创建访问令牌

打开右上角的头像点击设置再点击应用后点击创建访问令牌，令牌名称顺便，权限全部选择读写，仓库选择全部，然后点击生成令牌后把令牌复制到一个安全的地方就可以了

上传代码到仓库

输入以下命令
hexo clean && hexo g && hexo d

运行后会要求你输入用户名和密码，密码就是访问令牌

启用codeberg pages服务

打开仓库页面，点击右边扳手图标的设置，选择Web钩子，点击添加Web钩子，选择Forgejo，打开后目标URL填入
https://用户名.codeberg.page
最后点击更新web钩子,等待几分钟就可以得到你的个人博客了

Gruvbox配色主题补完计划

前言

使用SteamCMD来下载创意工坊的mod

发表于 2026-07-12 更新于 2026-08-22 本文字数： 788 阅读时长 ≈ 3 分钟

前言

steam,一个PC游戏分发平台，也是最大的PC游戏分发平台，里面除了游戏还有一个创意工坊，允许玩家制作和发布游戏mod(模组)来提升游戏趣味性，很多游戏的mod都在steam的创意工坊里，但这是建立在有steam客户端和steam下载游戏的条件下，如果你没有steam客户端或者你的游戏不是steam下载的破解版，那么常规的方式就无法下载创意工坊的东西了,因为不管是网页端还是客户端打开创意工坊都是没有下载的按钮，只有订阅的按钮，没有办法下载到本地，这样就没有办法给破解的游戏下载mod来增加游戏趣味性了，本篇博文我将教你如何使用SteamCMD来下载创意工坊的mod

安装

SteamCMD是Steam 客户端的命令行版本,它的主要用途是通过命令行界面 安装和更新Steam上提供的各种资源，SteamCMD在三大发行版都是有对应的软件包的，这里已arch为例，在aur仓库可以找到安装包(需要使用yay或paru来安装)，其他安装查看官方文档
yay -S steamcmd

windows推荐使用WorkshopDL，图形化界面，多种下载方式
https://github.com/imwaitingnow/WorkshopDL

配置

安装完成在命令行输入steamcmd进入,SteamCMD支持匿名登录,不需要注册账号就可以下载大部分东西，使用以下命令来匿名登录:
login anonymous

steamcmd默认的下载目录是在家目录的.steam文件下，我们可以使用以下命令来更改下载目录(目录必须是绝对路径):
force_install_dir 路径

下载mod&使用

我们在浏览器打开steam创意工坊的网页:
https://steamcommunity.com/workshop/

在里面的搜索栏搜索你需要的游戏，这里已僵尸毁灭工程的真实车辆中控和仪表盘mod为例，打开mod的详情页面，复制当前网址，然后打开 https://steamworkshopdownloader.io/ 把刚才的网址粘贴到网站上，网站会自动解析，然后会问你”你知道SteamCMD是什么吗？你登录过SteamCMD吗？”,选择yes,这样就会显示下载命令
workshop_download_item 108600 3635591071

命令格式为workshop_download_item 游戏ID 模组ID 复制它然后在之前的打开steamcmd的终端输入，等待下载完成就可以了，然后就可以把mod导入到游戏里了，像僵尸毁灭工程linux版本会在家目录新建一个Zomboid文件夹，里面的mods文件夹就是mod存放的地方，不过你需要把下载好的mod解压才可以，不然游戏无法识别，添加后就可以打开游戏，在开始界面点击模组来启用它们了，随便说一下我的僵尸毁灭工程是在rutracker上下载的，相关下载页面:
https://rutracker.org/forum/viewtopic.php?t=5231547

让你的手机变成麦克风-micyou

发表于 2026-07-10 更新于 2026-07-11 本文字数： 576 阅读时长 ≈ 2 分钟

前言

如果你是台式电脑或者电脑的麦克风很烂，一说话就炸麦，这些硬件层面的问题降噪软件是无法解决的，要想解决就要从硬件层面莱解决，但是为了这个买个麦克风就有一点太那什么的了，如果可以使用已有的东西来利用那就很好了，这几天我在github就看到了一个项目-micyou:可以把你的手机麦克风变成你的电脑麦克风的软件,通过 Wi-Fi 或 USB (ADB/AOA) 连接

安装

micyou多端适配，支持linux和windows等等，如果你是arch你可以直接使用aur仓库来安装(需要yay或paru):
yay -S micyou-bin

如果是其他就请在发布页面下载:
https://github.com/LanRhyme/MicYou/releases

除了安装本体还需要安装adb才可以使用,adb也就是安卓调试桥，是一种功能多样的命令行工具，可与设备进行通信，详细介绍查看:
https://developer.android.com/tools/adb?hl=zh-cn

如果你使用的是linux,那主流的发行版仓库都是有adb的包的，这里已arch为例:
sudo pacman -S android-tools

其他细节查看micyou官方文档:
https://micyou.top/docs/quick-start

使用

安装好软件后打开，因为是图形化界面，所以也没有什么难操作的，只需要点几下就可以连接了，只需要确保端口一样和在同一个网络环境就可以了，这里以usb连接为例，把数据线(不是充电线)插上电脑和手机，在手机弹出是否允许电脑usb调试时点击永远同意，然后在电脑端点击连接后在点击手机端的连接就可以连接上了，然后就可以在比如obs或其他需要麦克风的软件来使用了，这里以obs为例，打开obs，在混音器模块选择麦克风右键选择设置，在设备一栏选择mic开头的，然后确定就可以使用手机麦克风来录音了，这里也十分感谢作者，让我可以在不用花钱的情况下提升麦克风声音质量，其他问题查看官方文档：
https://micyou.top/docs/faq

前言

nvim(neovim),一个一款基于Vim的文本编辑器，你可以理解为lua版的vim，因为nvim可以使用lua语言来配置，支持lua让nvim的启动速度变得更快，所以现在主流都是选择nvim来作为文本编辑器,那么本篇博文我将会教你如何配置nvim和安装插件，如果你连vim怎么退出都不会我建议你先看看官方文档(-:

安装nvim

archlinux直接使用包管理pacman安装:
sudo pacman -S neovim

新建配置文件

nvim我建议是不要把所以配置都写在一个文件下，不然在时间一长绝对会乱死，在.config目录下新建nvim文件夹:
mkdir .config/nvim

在nvim目录下新建init.lua文件(类似于vimrc)
touch init.lua

在安装插件之前我们需要先配置一些nvim本身，所以先不创建lua文件夹，因为那是插件管理器和插件的文件夹，那么我们打开init.lua
为了方便所以把vim.opt(类似:set)局部变量opt
local opt = vim.opt

行号在敲代码的时候十分重要所以我们需要开启
开启绝对行号
opt.number = true
开启相对行号
opt.relativenumber = true

在敲代码时如果代码被包裹(折行)了，也就是在当前行没有显示的内容自动到下一行了，如果是阅读文章这没有什么关系，但如果是敲代码的这就会破坏结构，所以如果不是阅读文章一般是关闭的
opt.wrap = false

在使用编辑器的时候我们可以高亮光标(高亮当前行或列)来更快清楚当前行数
开启高亮显示当前行
opt.cursorcolumn = true
开启高亮显示当前列(两个一起形成十字架,来驱除报错(-:)
opt.cursorline = true

在搜索的时候，为了方便所以建议是关闭大小写敏感的
opt.ignorecase = true
opt.smartcase = true

在默认的nvim中的剪贴板是不同步系统剪贴板的，所以我们需要设置同步
opt.clipboard:append("unnamedplus")
