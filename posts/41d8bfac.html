python学习笔记1:hello,world

发表于 2026-10-01 更新于 2026-10-02 阅读次数： 本文字数： 1.2k 阅读时长 ≈ 4 分钟

前言

在前几天我忽然发现我似乎还不会一个编程语言，而这对于一个折腾linux的人来说是不应该的，所以我打算学习一下python,顺便写几篇python学习笔记，正好不知道要写什么 而本篇博文就是这个系列的第一篇了，本文基于《Python编程从入门到实践(第3版)》这本书来学习，那么废话不多说就开始正文吧

Python是什么

Python 是一种动态的解释型语言，和Shell脚本语言这种很相似，由Guido van Rossum(吉多·范罗苏姆)在1989年圣诞节期间，为了打发无聊的圣诞节而编写的一个编程语言

相较于c语言的语法这种学习起来会较为简单，尤其是母语是英语的人更是如此，但是语法简单不代表学习简单容易，在网络上很多什么卖课的以此为由忽悠文科生的，事实上要是深入学习还是很难的，这又不是英语，死记硬背就可以了，更不要提那些卖课的资源质量了，python本身就是开源自由的，网上优质的文档也很多，所以没必要只盯着那些臭卖课的，其他参考维基百科

安装python环境

得益于我使用的linux系统自带python环境所以我并不需要这一个步骤，而windwos就需要到官方网站 下载对应的安装包进行安装了，所以说linux适合写代码没错的，只是很多专业软件不支持，例如cad，草图大师这些的，不然真的就是完美无瑕了

敲出你的第一行代码

使用你的文本编辑器新建一个.py的文件，新手可以使用微软大战代码 vscode 在里面安装python的插件，自动补全和一键运行无疑是方便的，不过过于依赖代码自动补全我认为不利于我的学习，所以我使用nvim作为我的文本编辑器来编写代码，那么在新建的文件下写入:
print ("hello,world!")

print也就是打印的意思，整行代码的意思就是打印括号里的内容到终端，括号里的内容也就是”hello,world!”了，也就是打印字符串到终端的意思了
然后wq保存，这时候在终端输入
python 你新建的文件.py

就会输出hello,world! 了，恭喜你，你的代码成功执行了

给你的代码添加一个变量

变量可以理解为你把一个东西增加了一个叫法，比如你把马铃薯叫作土豆(土豆不是花生吗?(闽南话))，让你需要和别人表达的时候直接说土豆就行了(不过对于台湾人可能就会引起不必要的误会了(-:)

那放在python就是a = b 了，说明了a就是b被赋值的标签，引用书里的话就是

变量常被描述为可用于存储值的盒子…更好的定义是变量是可以被赋值的标签，也可以说变量指向特定的值。

那我们在之前新建的文件里在print那行上面添加
a = "hello,world!"

不过变量名尽量不要和我什么的一样就是一个简单的字母，至少那个变量名要和变量指向的东西有关联什么的，比如这个功能的英文什么的，不能使用数字和特殊符号作为开头，然后不能包含空格如果有需要空格的部分在那里填充下划线

然后把print部分改成
print ("a")

保存后在终端输入 python 你新建的文件.py 运行
你会发现怎么只有一个a?我不是在上面把a=hello,world了吗，为什么是a不是hello,world

这是因为python把a识别为字符串了，因为括号里是”a”,而在python里，在文本两边加入””(也可以是’’，个人习惯使用””),python就会识别为字符串，而想要让a这个变量不被识别为字符串，你需要把括号里的””删除，只保留a,也就是
print (a)

这样修改好保存后再python 你新建的文件.py ,输出的结果就是hello,world!了

结尾

恭喜你到达了一个新的地方并迈出了第一步，让我们高呼“我能吞下玻璃而不伤身体”来纪念此刻吧
